我的第一篇博客

发表于2026-10-17|更新于2026-10-21|随笔

我之前一直觉得写博客是件很郑重的事：要有值得写的东西，要有漂亮的排版，要有人看。于是什么都不写。空白页放了很久，index.html 一直是 0 字节。

后来想通了——先有个能写的地方，比什么都重要。

为什么是初音未来

因为她的颜色好看。

认真的说：#39C5BB 这个青绿色很特别。它不像常见的科技蓝那样冷，也不像薄荷绿那样轻，放在深色底上有种「屏幕在发光」的感觉。深夜里看着舒服，写代码的时候盯着也不刺眼。

再加上樱花粉 #FF7FAE 做点缀——两色撞在一起，就是初音的样子。

这个博客会写什么

  • 代码：踩过的坑、想明白的事、抄来又改过的片段
  • 声音：在循环什么歌，为什么喜欢
  • 日常：一些不成体系的碎想法

不追求更新频率，也不刻意追热点。想写了就写。

「世界は、まだまだこれから。」——世界才刚刚开始。

站点是怎么做的

部分 做法
生成器 Hexo 8
主题 Butterfly 5，深色底 + 青绿配色
皮肤 手写 CSS 覆盖（source/css/miku.css）
配色 主色 #39C5BB，辅色 #FF7FAE
部署 GitHub Pages，main 分支根目录

想换文案？改 _config.yml 一个文件就够了。

那就这样，第一篇写完了。

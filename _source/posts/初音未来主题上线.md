之前的站点是一片空白：只有几个 0 字节的 `index.html`，打开什么都没有。这次干脆整套重做，
顺手把它做成了初音未来的样子。

## 三个设计决定

**1. 主色只用一个。** `#39C5BB` 是初音头发上的青绿。整个站点的强调色、链接、按钮、光晕、
进度条，都从这一个颜色派生。少量樱花粉 `#FF7FAE` 只出现在「需要跳一下」的地方——
渐变末端、悬停状态、本命曲卡片。

**2. 深色做底。** 青绿在浅底上会显脏，在深色底上才会"发光"。所以默认是夜；右上角可以切到昼，
浅色模式的青绿会自动压深一档（`#12A79E`）来保证对比度。

**3. 动效要克制。** 樱花花瓣、声波画布、头图浮动、卡片入场——都是低幅度、长周期的。
系统开了「减弱动效」时全部停掉。

## 页面一览

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 首页 | `/` | 头图 + 最新文章 + 标签云 |
| 文章页 | `/:年/:月/:日/:标题/` | 正文 + 目录 + 上下篇 |
| 归档 | `/archives/` | 按年 / 月分组的时间轴 |
| 标签 | `/tags/` | 标签云与单个标签页 |
| 关于 | `/about/` | 自我介绍与配色卡 |
| 404 | `/404.html` | 走调的页面 |
| 订阅 | `/atom.xml` | Atom 全文索引 |

::: note 地址没变
原有的 `/2026/10/17/hello-world/`、`/2026/10/17/我的第一篇博客/` 这两个地址完全保留，
收藏夹和历史链接都不会失效。
:::

## 技术栈：没有栈

没有框架、没有构建工具、没有 `node_modules`。只有一个脚本：

```bash
# 生成整个站点（约 120ms）
node _source/build.mjs

# 本地预览
node _source/serve.mjs
```

构建脚本做三件事：读 `_source/posts/*.md` 解析 front matter、渲染 Markdown、
套模板输出静态 HTML。语法高亮是自己写的 60 行正则，够用。

## 写一篇新文章

在 `_source/posts/` 里新建一个 `.md`，文件名就是 URL 里的别名：

```markdown
---
title: 标题写这里
date: 2026-10-18 21:00:00
tags: [随笔, 初音未来]
summary: 首页卡片上显示的一段摘要。
---

正文从这里开始。
```

然后 `node _source/build.mjs`，提交，推送。没有别的步骤。

```bash
node _source/build.mjs
git add -A
git commit -m "post: 新文章"
git push
```

## 改文案只要一个文件

站名、副标题、导航、头图标语、关于页、页脚——全部集中在 `_source/site.config.mjs`：

```js
export default {
  title: 'xxybg',
  subtitle: '初音未来主题博客',
  hero: {
    title: '把声音，写成文字',
    highlight: '声音',        // 被渐变高亮的词
    typing: ['初音未来 · 39 · 电子歌姬', '未来は、ここにある']
  }
}
```

改完重新构建即可。

::: miku 为什么是 39
日文里 3 读作「み」、9 读作「く」，合起来就是「ミク」。所以 39 是初音的代号，
也是这个站点处处出现的彩蛋——徽标、统计数字、配色卡。
:::

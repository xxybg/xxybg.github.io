## 提示块

三种配色，写 `::: tip` / `::: note` / `::: miku` 开头，`:::` 结尾。

::: tip 小技巧
提示块里可以放**行内样式**、`代码`、以及[链接](/about/)。
:::

::: note 说明
`::: note` 是默认的青绿色。
:::

::: miku 彩蛋
`::: miku` 是樱花粉，用来写点轻松的。
:::

## 代码

行内代码：`const miku = '#39C5BB'`。

带语言标记的代码块会自动高亮（支持 js / ts / bash / json / python / css 等）：

```js
// 主题色常量
const MIKU = {
  teal: '#39C5BB',
  pink: '#FF7FAE',
  night: '#070C12'
}

function glow(color, strength = 0.45) {
  return `0 0 32px -6px ${color}` // 发光阴影
}

export default glow(MIKU.teal)
```
